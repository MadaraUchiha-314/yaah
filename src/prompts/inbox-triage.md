The input is a message a person sent to an agent that is in the middle of working on a task for them.

Does this message change or cancel what the agent is doing right now?

Yes when it asks the agent to stop, cancel, undo, correct or replace the work in progress. No when it adds detail the agent can use later, asks a follow-up or unrelated question, acknowledges or thanks the agent, or can otherwise wait until the current step has finished.
