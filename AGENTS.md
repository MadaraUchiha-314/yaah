# Working in yaah

This repository is developed with [the-loop](https://github.com/MadaraUchiha-314/the-loop).
Read `.the-loop/harness-config.yaml` and the-loop's `the-loop` skill (and the relevant
skill references) before implementing a work item. Follow the work item's selected graph,
keep specs under `docs/specs/<id>/`, record verification evidence under
`docs/specs/<id>/evidence/`, and update affected docs under `docs/` with the code.
Use the-loop's ticket, comment, ask and PR verbs when available. Explicit user
instructions and the work item's frozen selections govern scope and approvals.
People and their roles are in `.the-loop/collaborators.yaml`.
